## 2 · Applied on the host, outside the repository

- The public map's second hostname now sends the same security headers as
  map.aprsagent.com (`nosniff`, `Referrer-Policy`, HSTS); it sent none.
- HSTS on the admin hostname and on the two other projects' sites.
- Four configuration files that hold a session secret were world-readable;
  they are now readable by root only.

## 3 · Not done, for the operator

1. **Rotate the admin panel's session secret.** It was readable by every
   local account until today. Rotating it logs every admin session out once.
   It is a credential, so it is the operator's step.
2. **The registry only grows.** 302,658 → 419,192 stations in six weeks. A
   station not heard for, say, 180 days could be dropped at load. That saves
   memory and makes the hourly full flush shorter. It also changes what the
   registry means, so it needs a decision first.
3. **20 packages wait for an upgrade** (none flagged security; unattended
   upgrades take those). They include the web SDR's `openwebrx`, which should
   be upgraded while someone watches the SDR.
4. **A live profile was not taken.** Attaching py-spy to the running agent
   was refused by the session's permission classifier. The CPU figure above
   is a sample and a lifetime average, not a breakdown.
