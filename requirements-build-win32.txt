# Exact build environment for the Windows (32-bit) executables.

# requirements.txt states what the application needs; this file states what a
# release was actually built against, so a build can be reproduced later
# instead of drifting with whatever PyPI serves that day.
#
# Interpreter: CPython 3.13.9, 32-bit (python.org "Windows installer (32-bit)")
#   Recreate with:
#     C:\Python313-32\python.exe -m pip install -r requirements-build-win32.txt
#     C:\Python313-32\python.exe -m PyInstaller aprs_agent.spec --noconfirm
#
# Two ceilings worth knowing before bumping anything here:
#
#   cryptography is held below 46 by atproto (every published atproto release
#   requires cryptography<46), not by the 32-bit target — the same cap applies
#   on 64-bit. 45.0.7 is the newest release that satisfies it.
#
#   cryptography stopped publishing 32-bit Windows wheels after 48.0.0, so if
#   atproto ever lifts its cap, 48.0.0 is the last version installable here
#   without a Rust toolchain. Beyond that, 32-bit Windows means dropping
#   Bluesky or moving the build to 64-bit.
