# Exact build environment for the Windows (32-bit) executables.
#
# requirements.txt states what the application needs; this file states what a
# release was actually built against, so a build can be reproduced later
# instead of drifting with whatever PyPI serves that day.
#
# Interpreter: CPython 3.13.9, 32-bit (python.org "Windows installer (32-bit)")
#
#   2026-08-26: the v3.2.97 build was made on CPython 3.13.15 32-bit, because
#   that is what winget serves for 3.13 now and 3.13.9 is no longer offered.
#   Same minor, same architecture, and every dependency below resolved to the
#   pinned version with a win32 wheel. Recorded rather than glossed: this file
#   is worth having only while it says what a release was ACTUALLY built with.
#
#   Recreate with:
#     C:\Python313-32\python.exe -m pip install -r requirements-build-win32.txt
#     C:\Python313-32\python.exe -m PyInstaller aprs_agent.spec --noconfirm
#
# The cryptography ceiling, stated correctly:
#
#   2026-09-15, v3.2.111: atproto 0.0.72 requires cryptography >=41.0.7,<51,
#   so the cap is no longer the limit. The 32-bit wheel is. Checked on PyPI
#   that day: cryptography 48.0.1 carries win32 wheels, 49.0.0 and 50.0.1
#   carry none. This build therefore moves 45.0.7 -> 48.0.1, which closes the
#   bundled-OpenSSL advisory (GHSA-537c-gmf6-5ccf). CVE-2026-69247, -69248
#   and -69249 are fixed only from 49.0.0 and remain in the 32-bit build;
#   the VPS runs 50.0.1. Closing them here means dropping Bluesky from the
#   Windows build or moving it to 64-bit.
#
#   An earlier version of this note said win32 wheels stopped at 48.0.0 and
#   that 48 had none; both readings came from pip backtracking logs rather
#   than from the index, and 48.0.1 has them.
#
#   2026-09-24, v3.2.130: httpx2 and httpcore2 2.10.0 -> 2.13.1. openai 3
#   pulls them in (httpx2<3,>=2.7.0), and 2.10.0 carries GHSA-8xx6-hgc6-gc2m
#   (high, decompression amplification, fixed in 2.12.0) and two moderate
#   advisories fixed in 2.11.0. Pure-Python wheels, so no win32 question. The
#   VPS runs openai 2.x and never had them.
